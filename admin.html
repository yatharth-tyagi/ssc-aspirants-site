Excel columns: Section, Question, A, B, C, D, Answer (A/B/C/D), Explanation. For Hindi, also fill Question (Hindi), A (Hindi) … D (Hindi), Explanation (Hindi); leave them empty for English-only questions.

For pictures, first upload them in Files, then type the file name (for example q12-figure.png). Maths formulas: write them between $ signs, for example $\frac{1}{x}$ or $x^2$.
