# SSC Aspirants Official – Website

Mock tests (Eduquity pattern), chapter-wise notes and PYQ papers for SSC exams.
Live: https://sscaspirants-official.in · Instagram: @sscaspirants_official

## Pages
| File | Page |
|---|---|
| index.html | Home |
| mock-tests.html | Mock Tests (all exams) |
| ssc-cgl.html, ssc-chsl.html, ssc-mts.html, ssc-gd.html, ssc-cpo.html, ssc-stenographer.html, ssc-selection-post.html, ssc-je.html | One page per exam (tabs: pattern, full mocks, section-wise, subject-wise, PYQs) |
| notes.html | Chapter-wise notes |
| note.html | Notes reader (note.html?id=preamble) |
| pyq.html | Previous year papers |
| test.html | Test screen (Eduquity style); test.html?id=<id> opens a test made in the admin page |
| admin.html | Admin page: add notes, tests, live tests, what's new, files (needs your GitHub key) |

## Files you edit most
| File | What it holds |
|---|---|
| data/notes.js | Notes content |
| data/subjects.js | Subjects and chapters (set ready: true to publish a chapter) |
| data/exams.js | Exam details and patterns |
| data/topics.js | Subject-wise test topics |
| data/tests.js | Tests made in the admin page |
| data/live-tests.js | Live tests on Home |
| data/whats-new.js | What's new on Home |
| assets/site.css | Colours (top of file), layout, screen sizes |
| assets/site.js | Side menu, top bar, themes, search |
| assets/logo.png / logo-mark.png / favicon.png | Logo, watermark logo, browser icon |

Plain HTML, CSS and JavaScript. No build step.
